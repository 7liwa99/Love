## INTRODUCTION 

                This project is a small interactive web-based e-card designed to create a cute and emotional experience for users.  
                The website includes animations, moving buttons, transitions, and dynamic content changes using JavaScript.

                The idea behind this project was to practice front-end development while creating something visually fun and emotionally expressive.



## TECHNOLOGIES 

             - HTML5
             - CSS3
             - JavaScript (Vanilla JS)
             - Google Fonts



## FEATURES 

        - Pulsing animated envelope
        - Smooth letter opening animation
        - Interactive "No" button that moves away
        - Growing "Yes" button effect
        - Dynamic text and image changes
        - Cute animated cat GIFs
        - Responsive centered layout
        - Custom background and themed UI




## WHAT I LEARNED 

                 Through this project, I learned:

                                                - DOM manipulation using JavaScript
                                                - Event listeners
                                                - CSS animations and transitions
                                                - Positioning elements with Flexbox
                                                - Using transforms and scaling
                                                - Debugging JavaScript syntax errors
                                                - Improving responsive UI structure
